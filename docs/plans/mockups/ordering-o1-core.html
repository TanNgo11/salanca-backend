4. Outbox chạy nhiều server

Transaction ghi đơn + dòng outbox→ Cron mỗi server: claim lô 50 bằng FOR UPDATE SKIP LOCKED, lease 5 phút→ Gọi consumer (email, cảnh báo…)→ Đánh dấu đã giao
Server chết giữa chừng → lease hết hạn → server khác nhận lại. Consumer idempotent theo event id nên không gửi trùng. Đã chứng minh ở O0 với 2 process.
  1. 1Lỗi thì retry backoff mũ có trần; quá số lần → cảnh báo outbox-stuck (O6).
